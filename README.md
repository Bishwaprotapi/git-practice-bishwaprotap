# Git Practice: Bishwaprotap Ray

> A practical Git and GitHub assignment featuring a small Python calculator.

## Overview

The program prints the student's name and today's date, then demonstrates calculator operations. The repository also records a complete workflow using commits, feature branches, merges, and GitHub.

## Project Structure

| Path | Purpose |
| --- | --- |
| `src/main.py` | Runs the calculator demonstration. |
| `src/utils.py` | Holds reusable calculator helpers. |
| `docs/project-description.md` | Describes the project and its goals. |

## Run the Program

```bash
python src/main.py
```
